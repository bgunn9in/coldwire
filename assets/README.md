# COLDWIRE branding

The original COLDWIRE logo was created for this project with ImageGen and
selected by the project maintainer. It depicts an angular C/W conductor
monogram with square contacts and an ice-blue frame. It is not copied from
the branding of Amnezia, Xray or any third-party VPN application.

`coldwire-logo.png` is the original generated PNG. `coldwire-header.svg` is
original project artwork that embeds those PNG bytes without modifying them.
Both are included under the project's [MIT license](../LICENSE).

The self-contained header has a dark background and works with light and dark
GitHub themes. It uses system monospace fonts, a quiet coordinate grid and a
Client → Entry A → Exit B → Internet diagram. It contains no scripts, external
font dependencies, tracking requests or claims about live deployment status.

The visual palette is `#070d13`, `#0e1922`, `#2d4653`, `#e6f1f5`, `#a5bac5`,
mint `#66dbb2`, ice blue `#67b7ff` and restrained violet `#baa0ff`.
Commands remain selectable text in standard Markdown. No account avatar or
external application's branding is changed by these files.
