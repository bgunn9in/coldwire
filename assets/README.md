# COLDWIRE artwork

The header and routing diagram use a terminal palette inspired by 1980s and 1990s cyberpunk. Cyan traces SPA messages, mint traces the AmneziaWG path and amber traces traffic routed through the ISP. The header embeds the original ImageGen C/W logo selected for the project.

The SVGs include titles and descriptions in English and Russian and carry the project’s [MIT license](../LICENSE).
