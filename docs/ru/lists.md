# Списки для раздельного туннелирования

[English](../lists.md) · [Главная проекта](../../README.ru.md)

Импортируйте один из файлов, чтобы направить часть IPv4-трафика через провайдера.

| Файл | Что идёт напрямую | Префиксы IPv4 |
| --- | --- | ---: |
| [`ru-direct.amnezia.json`](../../ru-direct.amnezia.json) | Все российские диапазоны из снимка RIPE, локальные сети и часть адресов за пределами этих диапазонов. | 1 097 |
| [`ru-services.amnezia.json`](../../ru-services.amnezia.json) | Локальные сети и российские диапазоны, в которые входят адреса выбранных сервисов. | 77 |

В короткий список вошли адреса 86 групп сервисов. Среди них Яндекс, VK, банки и госуслуги. В нём только адреса этих сервисов из российских диапазонов. Полный список включает ещё около 111 млн IPv4-адресов, чтобы сократить число маршрутов на старых клиентах Android. Если нужно оставить больше направлений внутри VPN, выберите короткий список.

## Импорт списка

В настройках раздельного туннелирования сайтов выберите режим, в котором адреса из списка идут мимо VPN. Импортируйте один JSON через **Заменить список**. Включите VPN и проверьте, что сайт из списка видит адрес провайдера, а сайт, открытый через туннель, видит адрес B. Если после импорта VPN перестал подключаться, отключите только раздельное туннелирование сайтов и повторите попытку. Работу `ru-direct` проверили на телефоне с активным VPN.

## Обновление списков

Запустите генератор с Python 3.10 или новее. Укажите новую папку для результата.

```bash
python3 update_lists.py --output generated/fresh-lists
python3 update_lists.py --offline --output generated/snapshot-lists
```

Первая команда загружает свежие данные. Вторая берёт снимки из `data/` и воспроизводит оба JSON из репозитория. Каждая команда создаёт два списка. В Windows используйте `python`, если интерпретатор установлен под этим именем.

Параметр `--vpn-only IPV4` оставляет указанный адрес в туннеле. Его можно повторить для нескольких адресов. `--entry IPV4` и `--exit IPV4` так же исключают адреса узлов из прямых маршрутов. Если адрес уже входит в исходные российские или локальные диапазоны, генератор остановится. [Источники и число маршрутов](sources.md)
