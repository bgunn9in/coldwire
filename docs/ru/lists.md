# Списки для раздельного туннелирования

[English](../lists.md) · [Главная проекта](../../README.ru.md)

Импортируйте один из файлов, чтобы направить часть IPv4-трафика через провайдера.

| Файл | Что идёт напрямую | Префиксов IPv4 в релизе |
| --- | --- | ---: |
| [`ru-direct.amnezia.json`](../../ru-direct.amnezia.json) | Все российские диапазоны из снимка RIPE, локальные сети и часть адресов за пределами этих диапазонов. | 1 097 |
| [`ru-services.amnezia.json`](../../ru-services.amnezia.json) | Локальные сети и российские диапазоны, в которые входят адреса выбранных сервисов. | 77 |

В короткий список вошли адреса 86 групп сервисов. Среди них Яндекс, VK, банки и госуслуги. В нём только адреса этих сервисов из российских диапазонов. Полный список включает ещё около 111 млн IPv4-адресов, чтобы сократить число маршрутов на старых клиентах Android. Если нужно оставить больше направлений внутри VPN, выберите короткий список.

## Импорт списка

В сборках COLDWIRE со встроенным меню списков отключите VPN и откройте **Подключение → Раздельное туннелирование сайтов → ⋯**. Выберите **Российские сервисы** или **Российские диапазоны IPv4**, затем подтвердите замену. Если скачать файл не удастся, приложение предложит список из комплекта. [Инструкция к клиенту](https://github.com/bgunn9in/COLDWIRE-amnezia-client/blob/feature/spa-admission/docs/spa.ru.md)

В настройках раздельного туннелирования сайтов выберите режим **Напрямую**. Импортируйте один JSON через **Заменить список с сайтами**. Включите VPN и проверьте, что сайт из списка видит адрес провайдера, а сайт, открытый через туннель, видит адрес B. Если после импорта VPN перестал подключаться, отключите раздельное туннелирование сайтов и повторите попытку. Работу `ru-direct` проверили на телефоне с активным VPN.

## Обновление списков

Задача GitHub Actions **Refresh Russian site lists for COLDWIRE** запускается раз в неделю и вручную. Оба JSON публикуются вместе в ветку `ru-lists`. При сбое источника остаётся доступна предыдущая пара файлов.

Установите Python 3.10 или новее. Для запуска меню панели на Ubuntu и Debian также нужен пакет `python3-venv`. Откройте **12 Update split-tunneling lists**. Выберите **1** для загрузки свежих данных или **2** для работы со снимками из комплекта. Пункт доступен до настройки серверов.

Для отдельного запуска скачайте и распакуйте `COLDWIRE-RU-Lists.zip`. На Windows откройте `COLDWIRE-Lists.cmd`. На Linux откройте терминал в папке с файлами и выполните `bash COLDWIRE-Lists.sh`. [Релизы на GitHub](https://github.com/bgunn9in/coldwire/releases/latest)

Генератор загружает свежие данные, сохраняет оба JSON в новой папке с датой и временем внутри `generated/` и печатает её путь. Чтобы указать свою папку, добавьте `--output`. С параметром `--offline` генератор воспроизводит файлы релиза из снимков в `data/`.

Если источник недоступен, панель покажет его имя и предложит собрать списки из комплектных снимков. В командной строке повторите запуск с `--offline`. Предыдущие папки со списками можно использовать повторно.

| Запуск со снимками | Команда |
| --- | --- |
| Панель, Windows | `COLDWIRE-Admin.cmd update-lists --offline` |
| Панель, Linux | `bash COLDWIRE-Admin.sh update-lists --offline` |
| Отдельный запуск, Windows | `COLDWIRE-Lists.cmd --offline` |
| Отдельный запуск, Linux | `bash COLDWIRE-Lists.sh --offline` |

### Сравнение с прежними списками

Когда панель запросит папку для сравнения, укажите папку с двумя прежними JSON. Нажмите Enter, если сравнение не нужно. В командной строке используйте `--compare-with DIRECTORY`. Генератор покажет дату снимка RIPE, число добавленных и удалённых IPv4-префиксов и итоговое число маршрутов для старых версий Android. Посмотрите сводку перед импортом нужного JSON.

Параметр `--vpn-only IPV4` оставляет указанный адрес в туннеле. Его можно повторить для нескольких адресов. `--entry IPV4` и `--exit IPV4` так же исключают адреса узлов из прямых маршрутов. Если адрес уже входит в исходные российские или локальные диапазоны, генератор остановится. [Источники и число маршрутов](sources.md)

## Результаты проверки на Linux

Архивы релиза проверили в пяти локальных виртуальных машинах amd64 под QEMU/WHPX. У каждой было одно виртуальное ядро и 1 ГиБ памяти. На каждой системе запустили `COLDWIRE-Lists.sh` со снимками через `--offline` и со свежими данными. Затем открыли панель через `COLDWIRE-Admin.sh` и выбрали пункт **12** до настройки серверов. [Релиз, который проверяли](https://github.com/bgunn9in/coldwire/releases/tag/spa-panel-5e0d77838652)

| Дистрибутив | Python | Отдельно, офлайн и онлайн | Пункт 12 панели |
| --- | --- | --- | --- |
| Ubuntu 22.04.5 LTS | 3.10.12 | Прошло | Прошло |
| Ubuntu 24.04.5 LTS | 3.12.3 | Прошло | Прошло |
| Ubuntu 26.04.1 LTS | 3.14.4 | Прошло | Прошло |
| Debian 12 | 3.11.2 | Прошло | Прошло |
| Debian 13 | 3.13.5 | Прошло | Прошло |

У всех 30 файлов проверили формат JSON и число маршрутов для старых версий Android. На каждой системе офлайн-списки побайтово совпали с файлами релиза.

В онлайн-прогонах использовали снимок RIPE от 22 ноября 2026 года и версию каталога `d49d6fb2ce27417a03169c3cf365fabfd3f7932a`. Получилось 1 095 префиксов в полном списке и 76 в коротком. На Ubuntu 24.04 между двумя запусками изменился один префикс в коротком списке. Для старых версий Android получилось 740 маршрутов при отдельном запуске и 736 через панель. Генератор запрашивает адреса сервисов через DNS, поэтому короткий список может меняться между онлайн-запусками. [Контрольные суммы SHA-256](../lists.md#sha-256)

### Выбор источника и переход на офлайн

С новым меню повторили проверки на всех пяти виртуальных машинах. На каждой запустили отдельную утилиту и панель со свежими данными и с комплектными снимками. Затем заблокировали обращение к RIPEstat, чтобы проверить переход на офлайн. Панель назвала источник сбоя и после подтверждения создала новую пару файлов. При сравнении двух офлайн-пар панель показала ноль изменений. Контрольные суммы прежних файлов совпали.

В GitHub Actions оба ZIP проверили на Windows и Linux. Скрипты из распакованных архивов воспроизвели комплектные списки. [Прогон GitHub Actions](https://github.com/bgunn9in/coldwire/actions/runs/45282319496)

## Проверка импорта на Android

Оба свежих списка по очереди импортировали в AmneziaVPN 5.1.1.10 в эмуляторе Android 10 x86-64. Эмулятор подключили к локальному узлу AmneziaWG 3.1. Каждый раз выбирали **Напрямую** и **Заменить список с сайтами**. Тестовый HTTP-сервер записывал адрес источника. Для обоих списков запрос на адрес из исключений пришёл напрямую, а запрос на контрольный адрес пришёл с IP клиента в туннеле.
